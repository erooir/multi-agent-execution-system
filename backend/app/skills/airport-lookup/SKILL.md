# 机场要素检索

## 任务方法

在 OurAirports 离线快照中检索机场要素：

1. 先判断输入是单一机场查询，还是“大城市机场”等需要拆分的集合任务。
2. 单一机场可直接使用 ICAO/IATA；城市名必须转换为数据集使用的英文名称。
3. 集合任务先形成一个规模适中的代表性城市清单，再对每个城市分别调用
   `aviation.ourairports.lookup_airport`。不要把“机场、ICAO、IATA、坐标、跑道、
   海拔”等字段说明拼成一个查询词；工具的 query 只接收一个代码、机场名或城市名。
4. 检查每次返回；英文城市名无结果时，改用已知 ICAO/IATA 或更精确的英文机场名重试。
5. 合并实际工具结果，保留快照日期和证据条目，不得凭常识补造未返回的机场字段。

## 边界

- 完全离线（本地 CSV 快照），drill 演练模式下也真实执行。
- 工具数据中的名称和 municipality 主要是英文；中文城市名不得原样提交。
- 每次工具调用只查询一个城市或一个机场；集合任务可进行多次受控调用。
- 快照数据有日期，结果不代表现时航行资料；正式运行前需人工核对有效 AIP/NOTAM。
