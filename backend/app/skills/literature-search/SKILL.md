# 科技文献检索

## 任务方法

跨 OpenAlex 与 Crossref 两个公开文献库检索科技情报：

1. 接收检索词与条数上限。
2. 依次调用 `research.openalex.search_works` 与 `research.crossref.search_doi`。
3. 返回标题/DOI/年份/作者/被引数/来源等结构化条目，证据注明来源 URI
   与获取时间；两库结果并列呈现，不做未核验的合并去重。

## 边界

- 只读公开接口；仅外发检索词，绝不外发本地资料内容。
- 检索结果仅是线索，引用前需人工核对原文。
- 演练模式下只做预检（dry_run），不发起真实网络请求。
