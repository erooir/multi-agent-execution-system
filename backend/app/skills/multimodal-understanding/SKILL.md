# 多模态理解

## 任务方法

通过预算网关分析获准外发的图片资料：

1. 校验资料存在、属于当前项目、可见性为 external 且为图片格式。
2. 本地限定（local）资料一律拦截并记录审计，绝不发送到外部模型。
3. 演练模式不模拟图像分析结果，明确报错。
4. 外发图片限制 8 MB；唯一的模型调用是经 `model.vision.analyze`
   走预算网关的视觉理解请求。
5. 返回模型文本、用量与资料 ID；不推测图片中不可见的事实。

## 边界

- 这是唯一会外发资料内容的能力；所有调用经过预算网关计费与审计。
- 需要支持图像输入的模型配置，未配置时明确不可用。
