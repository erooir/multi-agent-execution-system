# PDF 图表读取

包含统计图的 PDF；交付读取表、来源位置、总数核对和不确定项。

1. 先读正文和图表页，明确统计窗口、单位、系列和脚注。
2. 无法从原生文本获得标签时使用 pdf_ocr，保留页码、图像索引和边界框。
3. OCR 数值只是候选阅读，逐项核对系列、月份/类别与覆盖范围，禁止从图形高度猜造精确数。
4. 用确定性统计复算总数；局部月与完整月分别计数，正文叙述必须与最终表一致。
5. 缺失/含糊标签说明未确认；不得为凑总数反推或修改原值。
