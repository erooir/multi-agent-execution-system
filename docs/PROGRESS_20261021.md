## 本轮补齐的产品与功能缺口

1. 流程从 JSON 编辑改为可视化 DAG：添加/删除节点、选择已发布智能体、连线或依赖勾选、即时循环检查、自动布局及节点参数表单。后端仍执行最终发布校验和版本冻结。
2. 智能体详情展示职责、能力、工具/技能、复合成员、关联流程和版本字段差异；配置复用与任务实例保持分离。
3. 任务产物按内容展示表格、文本、原文摘录、引用证据和图片元数据；表格有搜索和分页。逐产物质量检查、硬问题与独立评审建议可直接阅读，完整 JSON 作为诊断入口保留。
4. 提交前可主动检查匹配与授权，展示实际候选智能体及版本；提交时重新校验。时效类别进入后端冻结快照并实际影响队列，而非只增加一个界面标签。
5. 新增项目授权范围内的运行观测：当前排队、活动任务、最长等待、真实终态端到端 p50/p95、失败原因和关联 Worker 心跳。明确统计窗口、样本数和不包含演练；没有样本时不显示虚假时延。
6. 开发依赖 Vite 从 6.4.3 更新至 6.4.4，修复当前审计报告中的 launch-editor 问题，保留原主版本。依据：[维护者安全公告](https://github.com/vitejs/launch-editor/security/advisories/GHSA-587h-7wmj-h5pm)。

验证结果以 `docs/VALIDATION.md` 的 2026-10-21 记录为准；不能把测试用例数量转为业务完成率。
