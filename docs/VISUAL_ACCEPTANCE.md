## 已验证范围

本次样本覆盖高对比印刷文本、单色简单几何图形、无重叠目标计数、多图分别引用及对缺失日期的保留。一次任务、两张图不足以估算总体准确率，也无法说明对航拍或真实复杂场景、遮挡、密集对象、低照度、小字、多语言、确切地点、时间或事件归因的正确性。自动评审通过时仍需结合独立标注判断具体能力。自然场景验收可使用具有合法授权的民事档案或公共展览图片，预先定义观测清单、不可判项目和标注协议，再按图像质量分层统计。
