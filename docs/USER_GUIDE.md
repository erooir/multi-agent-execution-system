# 航智平台使用手册

## 开始使用
打开本机8000端口登录。现有账号继续有效；新账号注册后为操作员。管理员可在项目权限页配置成员。首次进入会建立个人工作空间和可执行的基础智能体模板，不创建虚构任务或指标。

## 智能体
在智能体目录按通用/专用、元/复合筛选。创建或编辑定义后发布为不可变版本。参数只允许已登记的工具配置。复合定义绑定成员的具体版本；发布检查循环、嵌套深度及权限。

停用阻止新调用，已受理任务仍使用冻结快照。退役不再作为新资产使用。销毁采用保留历史的逻辑删除；存在流程、复合成员或运行任务引用时拒绝。版本页和实例页用于定位实际运行上下文，不代表常驻独立模型进程。

## 数据与知识
登记文本或结构化内容，或上传UTF-8文本、JSON、CSV及媒体文件。每份数据必须有来源标识、版本与说明。默认仅本地；只有确认可外发的公开数据才能选择public并用于云模型。上传上限10MB，内联文本上限2MB。

撤回来源后禁止后续读取和新任务引用，关联记忆失效。有效期按登记策略执行。知识检索返回真实片段和来源；当前记忆写入仅接受可在来源中逐字定位的片段，避免把推断当事实。

## 任务
创建任务时选择项目、输入、任务类型、输出质量门槛、截止时间和费用上限。可以选择已发布流程，或让平台匹配已发布能力。幂等键相同且内容一致时返回原任务；键相同但请求不同会拒绝。

- 本地：真实确定性工具，无模型推理费用。
- 云端：公开资料通过统一网关；任务预算在每次调用前检查，包含独立评审。
- 演练：明确标记，只运行已实现工具，不证明离线模型能力。

任务提交后不需要人工审核。执行器进行自动校验、评审及最多两轮修订。成功、部分完成、失败和取消都保留原因。只有预先允许部分交付才会产生partial。任务流程图可展开实例、版本、真实产物和事件。

取消是请求；仍在执行的调用不会提前标为已释放。不确定外部费用保留预留。工作进程重启会按租约接管，可确认的完成节点复用，未确认的模型调用不会盲目重放。

## 周期任务
使用持久计划配置间隔与时区。页面关闭后仍由Worker触发。错过多个时段时合并至最近到期时段，事件记录错过数量。每次触发重新验证创建者身份、项目和数据。权限失效或输入不可用会停用计划并显示错误。

## 改进
从至少两个独立完成任务建立冻结评测，最后一个样本作为保留样本。平台实际重跑基线和候选，保存原始输出、质量检查与耗时。权限扩张、硬失败、回归或没有可测质量增益都会拒绝晋升。已发布版本可回滚，正在运行的任务不更换快照。

自动改进需要管理员事先配置 HANGZHI_AUTO_IMPROVE=true，目前仅限本地提取式文本的覆盖长度参数，不能修改代码、模型权重、依赖或权限。无保留集或没有可验证增益时保留稳定版本。

## 监控
任务、实例、节点和账本为状态唯一来源。Worker心跳超过阈值显示离线。成功率必须与样本数和统计范围一起阅读，零样本不计算成功率。项目总预算为保守占用而非供应商账单实扣。退出登录需要确认。
