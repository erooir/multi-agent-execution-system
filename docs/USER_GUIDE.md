# 航智 · 航空情报平台使用说明

本说明帮助使用者在本机完成“提出研究任务—配置流程—检索资料—生成报告草稿—人工审核—导出成果”的全过程。平台基于 Agno AgentOS，预置三个研究项目、四类智能体、六条流程模板和 30 条任务样例。预置资料均为合成演示数据，不对应真实研究结论、地理位置或事件。

## 1. 启动与登录

准备 Python 3.12、uv 和 Node.js 22 或更新版本。在项目根目录打开 PowerShell，首次启动执行：

```powershell
uv sync --frozen --python 3.12
powershell -ExecutionPolicy Bypass -File scripts/start.ps1
```

启动脚本会安装缺少的前端依赖、构建界面并启动本机服务。首次安装依赖需要联网。看到就绪提示后，打开 [本机工作台](http://127.0.0.1:8000)。服务默认只监听 `127.0.0.1`，不需要购买 AgentOS 云端订阅。

以后可继续使用同一启动命令。前端代码没有变化时，也可跳过构建：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/start.ps1 -SkipBuild
```

停止服务：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/stop.ps1
```

首次使用时，在登录页选择“注册”，输入用户名、密码和确认密码，显示名可选。用户名为 3–32 位英文字母、数字或下划线，密码为 8–128 个字符。注册成功后自动进入工作台；之后使用同一账号登录，服务重启后账号仍保留。

| 角色 | 主要权限 |
| --- | --- |
| 管理员 | 管理资源、运行任务、审核报告、修改预算及运行设置 |
| 研究员 | 管理项目、资料、智能体和流程，运行与重试任务，编辑报告；不能批准审核或修改系统设置 |
| 审核员 | 查看资料与运行记录，审批任务、编辑及恢复报告；不能创建运行或修改流程 |

自行注册的账号默认为研究员，注册页不提供管理员或审核员选项。已有管理员和审核员账号继续有效。需要切换账号时，使用侧栏退出按钮后重新登录。当前版本为本机共享工作空间，各账号可查看同一组项目；尚未提供团队邀请、租户隔离或忘记密码功能。

真实模型使用 Windows **用户环境变量** `deepseek_api_key`。请通过系统环境变量设置保存密钥，不要把值写入代码、浏览器输入框、文档、截图或 Git。当前应用模型标识为 `deepseek-flash`。在“系统与审计”中查看密钥是否已配置，界面不会返回密钥内容。

## 2. 先分清两种执行模式

| 模式 | 实际行为 | 是否产生外部模型费用 |
| --- | --- | --- |
| 本地演练 `rehearsal` | 用本地规则规划，执行真实本地检索、解析及确定性报告整理；运行与报告保留演练标识 | 否 |
| 真实模型 `live` | 通过预算网关调用 DeepSeek，进行任务规划、分析及报告生成；流程中的本地技能仍在本机执行 | 是 |

**本地演练不是离线大模型推理。** 它用于验证资料、流程、审核和报告链路，不代表模型研究质量。中文语义检索和 OCR 是真实的本地模型能力，但不会因此将演练变成完整离线 LLM 系统。完整隔离环境下的大模型推理仍需后续接入本地模型服务。

页面中的生成流程、角色测试、技能测试、任务运行和样例评测分别提供模式选择。每次提交前检查当前选择；真实模型模式会发送该次任务输入、必要的角色指令、审核反馈以及允许外发的资料上下文。

## 3. 第一次完成航空科技研究

### 3.1 选择项目和任务

1. 登录后，在顶部选择“航空科技专题研究”。
2. 打开“资料与知识”，确认能看到合成的复合材料摘录、民航低碳技术资料、文献登记表等。
3. 回到“工作台”，输入：

   > 整理合成资料中 2024—2026 年民用航空复合材料研究的主题变化，比较研究方法，列出证据限制，生成带来源的专题报告并提交人工审核。

4. 首次可选“本地演练”，点击“生成研究流程”。切换到“真实模型 · 计费”后，生成流程本身也会调用模型。

也可直接进入“流程与模板”，使用“航空科技专题研究”或“文献方法对比与核验”等预置模板。需要保留原模板时先复制，再修改副本。

### 3.2 编辑、校验与发布

在流程画布中，可以拖动节点、连接端点、修改名称、绑定智能体和技能，并编辑右侧节点配置。建议先保留以下主线：

```text
开始 → 需求解析 → 知识检索 → 条件判断 → 批量整理 → 分析推理
                                       ↓
                                报告草稿 → 人工审核 → 结束
```

条件判断的“通过”和“不通过”端口必须分别连接。预置模板在证据不足时转入待核报告草稿，再等待人工审核；有证据时先批量分析，再生成草稿。

常用配置示例：

| 节点 | 配置 | 含义 |
| --- | --- | --- |
| 知识检索 | `{"limit":8}` | 返回最多八条证据 |
| 条件判断 | `{"min_evidence":1}` | 至少有一条证据才走通过分支 |
| 批量处理 | `{"items":["技术主题","研究方法","证据限制"],"count":3}` | 逐项处理三个研究维度 |
| 分析推理 | `{"instruction":"比较方法并明确数据不可比之处"}` | 补充该节点的分析要求 |
| 报告生成 | `{"template":"technology"}` | 使用科技情报专题报告模板 |

其余报告模板标识为 `geography`、`situational` 和 `summary`，分别对应地理分析、态势研判和任务执行摘要。批量处理一次最多十项；首版流程为无环图，不支持无限循环或任意用户代码执行。

完成修改后点击“校验”，按提示修复断开的节点、无效绑定和分支问题，再点击“发布”。保存或恢复流程会生成草稿，**草稿需要重新发布才能运行**。运行记录会保留当时的流程版本和快照，后续修改不会替换已经启动任务的流程。

### 3.3 发起运行并查看草稿

发布后返回“运行中心”，点击“发起研究任务”：

1. 选择已发布的流程和“航空科技专题研究”项目。
2. 填写具体研究需求，选择“本地演练”或“真实模型”。
3. 可指定参考资料；未指定时，流程按当前项目检索资料。真实模型任务不要选择“仅限本地”的资料。
4. 点击“开始运行”，打开任务详情。

“节点时间线”显示实际节点状态；选择节点可查看输出和错误。“引用证据”显示本次实际检索到的片段及来源位置，“执行日志”记录过程事件。

报告节点先产生草稿，随后任务进入“待审核”。此时已经可以查看研究报告，但不代表人工审核已经通过。刷新或关闭页面不会删除已保存的运行、证据和待审核状态。

### 3.4 审核、引用检查与导出

由 `admin` 或 `reviewer` 在“运行中心”点击“审核当前结果”，也可从“审核与报告”的待审核提示进入：

1. 阅读草稿，核对事实、推断和证据限制。
2. 在“引用来源”或运行的“引用证据”中核对文档名、位置、原文片段和来源 ID。需要查看完整文件时，到“资料与知识”下载原文件或查看分块。
3. 在审核稿中直接修改内容并填写审核意见。请保留来源编号、合成资料声明和演练标识。
4. 选择“通过并继续执行”，报告形成新的已审核版本，任务继续到结束；选择“退回 / 不通过”，任务停止并保留意见，研究员可按反馈重试。

“审核与报告”支持编辑正文、查看版本、恢复历史内容，以及导出 **Markdown、Word DOCX、HTML**。恢复历史版本会生成一个新版本，不会删除原有历史。编辑或恢复后的报告是草稿，不自动继承原版本的审核状态；当前审批入口依附任务中的人工审核节点。

正文中的来源标识用于核对引用。系统保留实际检索证据，但报告事实是否充分、论证是否成立，仍需审核人判断。

## 4. 导入资料与控制外发

在“资料与知识”点击“导入资料”，选择项目、文件和使用范围。当前网页上传单个文件上限为 **20 MB**，常用格式包括 TXT、Markdown、CSV、PDF、DOCX 和 PNG/JPEG/WEBP 图片。文档解析接口另支持 JSON；图片解析能力还支持 BMP。

| 使用范围 | 可使用的能力 | 对真实模型调用的影响 |
| --- | --- | --- |
| 仅限本地 `local` | 本地解析、关键词检索、语义检索、OCR、本地演练 | 禁止作为云端模型上下文；显式选择这类资料启动真实模型任务会被拒绝 |
| 允许外部模型 `external` | 本地能力及获准的外部模型分析 | 相关片段或图片可以经过预算网关发送至 DeepSeek |

上传默认选择“仅限本地”。只有确认资料可以发送给外部模型后才选择 `external`。这个标记约束已登记资料的处理路径；研究需求、角色指令和审核反馈属于用户主动输入，使用真实模型时也会发送，不应粘贴仅限本地的内容。

文档导入后会产生带位置的分块：PDF 使用页码，DOCX 使用段落编号，文本使用行号，CSV 使用行号，JSON 使用记录位置。上传图片后，需要运行 OCR 才能得到可检索文字分块。

**扫描 PDF 目前需要先导出为图片，再使用 OCR。** 没有文本层的 PDF 可能显示需要 OCR，不能把零分块误认为成功提取。普通文档解析也不负责恢复复杂版面、解释图表或识别图片中的文字。

项目根目录里的背景文档不会被自动扫描或索引。平台只读取显式上传的文件和预置合成资料。

## 5. 六项技能的使用

进入“技能工具箱”，点击相应技能的“测试技能”，选择项目、输入查询，并按需要选择具体资料。解析、OCR、多模态必须选择资料。初次测试建议选择一份已知资料，便于核对结果。

| 技能 | 实际用途 | 当前边界 |
| --- | --- | --- |
| 知识库检索 | 对本地文本分块进行关键词检索，返回来源与位置 | 无匹配会返回空结果；不是互联网搜索 |
| 图谱查询 | 查询 SQLite 中已经登记的实体和关系 | 预置关系来自合成样例；上传新文件不会自动构建完整知识图谱 |
| 文档解析 | 读取支持格式的文字和结构化记录，并提供可引用分块 | 不等同于 OCR；加密 PDF 不支持 |
| OCR 识别 | RapidOCR 在 CPU 上识别上传图片，保存文字、区域及置信度，并加入本地索引 | 支持图片；扫描 PDF 先转图片，低清或复杂图片需要人工校对 |
| 语义检索 | 使用中文 BGE 模型在 CPU 上计算向量并检索本地片段 | 首次使用可能下载公开模型；模型不可用时明确报错，不会冒充关键词检索成功 |
| 多模态理解 | 经预算网关把允许外发的图片交给视觉模型分析 | 需选择真实模型模式及 `external` 图片；外发图片上限为 8 MB，本地演练不模拟图像理解 |

预置的“合成资料 OCR 与图文理解测试”图片可用于比较 OCR 提取文字与多模态分析结果。文字中的编号、数量和年份均为虚构测试内容。

中文 BGE 模型缓存位于 `.local/models/fastembed/`。第一次准备需要网络与磁盘空间；下载的是公开模型权重，资料向量计算留在本机。模型准备完成后，后续加载仍可能需要数秒。可在“系统与审计”查看语义模型状态；“未加载”不等于检索结果已经失效。

## 6. 使用 30 条任务样例评测

“样本评测”提供覆盖三个场景的 30 条合成任务样例。选择部分样例或全部样例，默认按样例匹配流程，也可以指定已发布流程。先用本地演练检查链路，再根据需要进行真实模型评测；真实模式批量评测会产生多次模型调用。

当前评测检查三项可自动验证的行为：

1. 是否到达完成状态或人工审核门。
2. 是否产生分析正文。
3. 引用能否解析到已保存的资料与分块。

三项全部满足才记为规则检查通过；报告是否生成另行记录。**等待审核可以表示流程正确到达审核门，不表示已经通过人工审核。** 评测得分及规则通过率不是事实准确率、目标识别准确率、专家质量评分，也不能直接作为项目材料中研究指标已经达标的证据。

点击某条结果的“查看运行”，可以核对具体节点、引用和失败原因。需要评估研究质量时，应另外制定人工标注标准和评审记录。

## 7. 故障定位与恢复

| 现象 | 检查与处理 |
| --- | --- |
| 网页无法连接 | 检查启动输出和端口；查看 `.local/server.stderr.log`、`.local/server.stdout.log`。可访问 `/api/health` 检查服务状态 |
| 提示流程为草稿或结构无效 | 回到“流程与模板”校验并发布；确认开始、结束、依赖、技能绑定和条件分支完整 |
| 检索为空 | 检查项目、所选资料、分块数量及查询词；图片先 OCR。空结果不应通过编造来源补齐 |
| 语义模型准备失败 | 查看系统中的模型状态，检查下载网络及缓存；准备完成后重试。需要时明确改用关键词检索 |
| 真实模型失败 | 查看失败节点及系统状态，检查密钥是否配置、网络、服务商账户状态和预算余量。不要在日志或截图中粘贴密钥 |
| 任务处于待审核 | 由管理员或审核员审阅报告并提交决定；研究员不能批准自己的运行 |
| 审核退回 | 查看审核意见，由研究员点击重试，系统从需要重做的分析或报告节点继续，保留上游证据 |
| 服务重启后显示中断 | 检查已保存节点结果及预算记录，再显式重试；系统不会自动重新发出不确定的模型请求 |
| 已取消但仍有费用 | 取消阻止后续执行；已经发送的外部模型请求可能继续完成或计费，预留不会因此自动清零 |

运行中心的重试保留已完成节点，继续未完成部分；审核退回会按反馈重新执行相关下游节点。关闭网页与取消任务不同：关闭网页不会主动停止后端任务。

报告编辑、恢复、审批以及资源变更可在“系统与审计”查看操作记录。排查模型故障时，先保留账本和错误记录，避免连续重复提交相同请求。

## 8. 模型预算与本机数据

本项目模型调用累计授权上限为 **300 元人民币**。每次请求在发送前预留最坏情况下的费用，收到可靠 usage 后再结算。失败、超时或费用不确定的请求会继续占用预留，重启服务不会释放这些记录。

当前预算采用保守计账：按已核验高峰单价的两倍余量计算，输入每百万 token 4 元、输出每百万 token 16 元，不计缓存及非高峰优惠。页面数值是预算占用上界，**不是服务商实际账单实扣金额**。价格变化后应先复核网关费率。管理员可以调低总额，但不能通过界面把授权提高到 300 元以上。

预算账本位于 `.local/budget.sqlite3`。**不要删除、替换账本或更换数据目录来重置预算。** 该额度只覆盖本项目预算网关发出的调用，不包括同一账户在其他程序中的使用。

`.local/` 保存应用数据库、上传文件、模型缓存、运行日志和其他本机数据。备份时应停止服务并完整保留相关数据；不要为了“清空演示”删除预算账本。

## 9. Git 与资料边界

Git 用于管理代码、依赖锁文件和可公开的开发文档。原始项目背景 DOCX/PPTX、上传资料、报告产物、数据库、日志、模型缓存和密钥都不应提交。

仓库提供提交前检查，可在项目根目录启用：

```powershell
git config core.hooksPath .githooks
```

提交前仍需检查暂存内容，不要强制加入被忽略的原始文件或 `.local/`。演示资料即使允许外发，也应保留合成声明，不能展示为真实业务数据或真实研究成果。
