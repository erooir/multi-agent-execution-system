# B05：从创建任务开始的公开资料演示

演示使用联合国乌克兰人权监测团公开报告，目标是从原始 PDF 整理月度伤亡数据、复算总数并说明统计限制。不要选择历史任务代替创建，不向任务预填正确答案。

## 准备

- 新版本机入口：`http://127.0.0.1:8001/`。管理台为同一地址下的 `/manage`。旧版 8000 保留，勿混用。
- 登录已有账户，选择“新版演示 · 公开资料”项目。账户密码保存在本机，未写入本页或新建固定默认密码。
- 公开原件：`B05_OHCHR_Ukraine_civilian_casualties_2023.pdf`，本机演示副本位于忽略目录 `.local/demo/`。原件不随 Git 上传。
- 原件公开来源：[联合国乌克兰办公室发布的 PDF](https://ukraine.un.org/en/download/127169/219519)。已校验副本 SHA-256 为 `96ef41b8bc88f30888ac3fb5f01c8313726b8d4b81eea2e1d9009ee463685059`，共 13 页。
- 本机启动包装脚本为 `.local/start-autonomous.ps1`，使用已部署 DM8、原历史预算账本、媒体依赖及隔离脚本环境。复制此工作区到其他机器不等于这些依赖已安装。

## 现场操作

1. 在首页新建任务，将下面这段填入“任务目标”，可在“交付要求”中补充希望的格式。任务标题由平台生成，不填案例 ID、算法名称或流程节点。

   > 请依据上传的联合国公开报告，整理统计期内每月的平民死亡、受伤及合计人数，区分完整月和部分月，复算月度加总与报告总数是否一致，并说明统计范围、核验限制。每项结论注明原件页码；若正文缺少月度数值，请检查报告图表，不得按总数倒推月份数据。

2. 选择云端模式，将本任务上限设为 2 元，明确授权本次任务说明与公开资料进入统一模型网关。额度是上限，实际费用按请求记录累计。
3. 查看平台解释的资料需求，在当前任务中选取上述 PDF，勾选“这些文件是允许用于本任务的公开资料”。无需先将 PDF 改造成 JSON，也无需预建知识库或向量库。
4. 点击“提交资料并开始分析”。平台校验实际文件，资料具备后自动匹配月度统计能力、绑定智能体、调用工具和审核；资料仍有缺口时说明原因并等待补充。
5. 展开执行记录，观察最初正文解析的月度数值缺口，以及是否触发“图表 OCR 复算”修订。查看修订原因、受影响步骤、工具调用和前后审核变化。
6. 结果完成后查看月度表、图表、完整/部分月份提示、复算结果及原文限制；打开 PDF 页码引用核对原件。可下载结果 JSON 留作汇报附件。

## 说明平台在做什么

- 用户只表达目标、提供资料并授权，执行器与工具选择由平台负责。
- 第一次解析无法从正文获得完整月度序列时，审核不会把有总数视为完成。修订会改变取数方法，读取图中印刷标签，再重新复算；不是重复相同提示词碰碰运气。
- 运行详情显示真实模型、智能体版本、工具调用、原件位置、审核和费用；目录中的可用工具数量不等于该任务实际用了多少工具。
- 数值与月份计数由工具产物复算。部分文字计数有确定性一致性检查，但不能据此宣称所有语言错误都已被证明不存在。
- 这是已知领域能力的复用演示。任意新任务的动态规划、任务级智能体和隔离脚本是另一条真实链路，不能把 B05 的固定领域处理器描述为模型临时编写的算法。

## 独立验收参照

以下数值只给演示人员用于核对，不能作为执行输入或预存结果：统计区间为 2022-02-24 至 2023-02-15，应得到 13 个月份，其中 11 个完整月、2 个部分月；月度死亡加总 8,006，受伤加总 13,287，合计 21,293，与报告同口径总数一致。图表在原件第 3 页，总数和统计说明可回到原件第 1 页核对。

必须保留报告的限制：统计为已核实记录，实际人数可能更高；两个部分月不能直接与完整月份比较。不能把总数一致解释为现实世界的全部事件均已被统计。

## 现场出现问题时

模型与网络响应时间不固定。让当前任务继续运行并查看真实状态，不连续重复提交。如果终止，保留失败原因和请求费用，补足资料或修复依赖后在同一任务继续。不能清空账本或把失败改成成功。

如现场网络不可用，可打开此前已完成的真实验收任务解释轨迹，并明确说明这是历史运行记录；不能声称离线页面正在调用云模型。完整离线大模型部署须另行配置并验收。
