# 新版界面设计

采用深色工作台与清晰节点样式；颜色和布局参考历史界面，业务信息架构独立设计。

主背景#151619、侧栏#121316、卡片#1d1f24，强调色#b3a6f7。正文16px，辅助文字不依赖低对比度。系统字体，不请求CDN或远程字体。键盘焦点、错误文本、禁用状态和响应式布局是基本要求。

导航围绕智能体、流程、任务、数据、计划、知识、改进和运维。目录与任务之间通过agent_id、version、instance_id关联。节点以类型、名称、绑定和状态形成层次，连接表达真实依赖。

空状态给出可执行入口，不生成假任务、假成功率或假曲线。网络错误和Worker离线独立于任务状态展示。用户可区分本地工具、云模型和演练；未接入的模态明确说明能力边界。
