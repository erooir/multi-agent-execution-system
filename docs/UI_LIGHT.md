## 变更边界

侧栏“当前项目”保留：它选择管理台的项目数据范围，资料、任务、智能体、流程、知识、评测及统计均受该范围和项目权限约束，不是装饰性选项。

首轮 Light 改版不修改后端、数据库结构、API 路径、Page ID、状态枚举、任务请求值、轮询节奏、权限、工具授权、模型网关或费用账本。该轮新增/调整的交互仅为说明展开、页面布局和 Light 画布呈现；不修改默认表单值或执行方式。

`styles.css` 提供统一语义颜色，`light-workspace.css` 提供 Light 布局与组件外观。主题完全使用本地 CSS 和已有图标，无 CDN、外部字体或新增包。

## 项目管理补充（2026-11-03）

按用户后续要求增加项目改名：进入「设置 → 项目与成员」，在对应项目行点击「改名」。有项目写权限的操作员和管理员可以修改名称，保存后选择器和页头同步更新。项目 ID、成员、资料、任务和已发布版本保留。

同名项目在管理台、页头和问答入口显示「名称 · 项目短编号」，短编号冲突时自动延长。名称唯一时只显示名称；项目表格继续显示完整 ID。已有同名项目保留，可以分别改名。

首次加载的默认项目初始化增加数据库事务锁，并在获得锁后重新检查可访问项目，防止多 API 进程同时创建默认工作空间。手动创建仍允许同名项目。这是用户追加授权的功能补充，不改变任务执行、项目权限或计费规则，无数据库结构迁移。
