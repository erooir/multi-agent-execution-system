# 航智管理台

React / TypeScript 管理界面，业务使用 `/api/v2`，身份使用 `/api/auth`。依赖、图标、字体回退和图编辑资源全部本地提供，没有 CDN。

```powershell
cd frontend
npm ci
npm run dev
npm test
npm run build
```

开发服务默认 `127.0.0.1:5173`，代理 API 到 `127.0.0.1:8000`。正式本机运行由后端提供 `dist` 静态文件。构建产物不包含密钥、数据或预置任务指标。

## 业务入口

- 智能体：用途和结构分类、定义编辑、不可变发布版本、生命周期、任务实例追溯。
- 任务：数据选择、类型与执行模式、质量和预算约束、持久计划、依赖图、事件、取消和产物。
- 流程与数据：节点和参数配置、版本发布、原始载荷登记上传、来源与有效期、撤回。
- 知识和改进：连接器、授权搜索、来源记忆、冻结评测候选、评测证据、管理员晋升和回滚。
- 运维：实际能力目录、Worker 心跳、累计账本、项目成员与审计。

界面定时读取持久记录。同步失败保留最后一次记录并明确标记；浏览器不推断任务成功、不自动释放在途实例。只有后端返回的真实记录进入仪表；配置演练从真实任务统计中排除。前端角色控制仅用于交互，权限以服务端执行为准。

## 验证

`npm test` 覆盖项目视图隔离、真实终态统计、空账本展示、依赖图定位、错误保真、同源凭据与多种资产响应。浏览器验收使用专门的合成账户与小型合成数据；截图和运行证据保存在忽略目录。移动布局支持折叠导航、独立表格滚动、键盘焦点、原生对话框和减少动画设置。
